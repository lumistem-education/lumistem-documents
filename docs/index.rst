Từ ý tưởng đến chương trình đầu tiên.
=====================================

.. container:: intro

   Chào mừng đến với tài liệu LumiSTEM. Tìm hiểu cách tạo khối lệnh,
   lập trình kéo thả và đưa chương trình lên thiết bị — bắt đầu ngay
   ở chế độ khách, không cần tài khoản.

.. container:: primary-link

   :doc:`Bắt đầu cùng LumiSTEM → <getting-started/quickstart>`

Khám phá bộ phần mềm
--------------------

Ba mảnh ghép, một hành trình sáng tạo. Chọn công cụ bạn muốn tìm hiểu.

.. container:: product-grid

   .. container:: product-card

      .. rst-class:: card-number

      01 / BUILD

      .. rubric:: LumiSTEM Kitchen

      Thiết kế khối lệnh và cấu hình bo mạch. Nhập, chỉnh sửa và xuất
      tài nguyên dưới dạng file JSON.

      :doc:`Khám phá Kitchen ↗ <kitchen/overview>`

   .. container:: product-card

      .. rst-class:: card-number

      02 / CREATE

      .. rubric:: LumiSTEM Blockly

      Kết nối các khối lệnh thành chương trình. Lưu dự án, xem mã
      và chuẩn bị chương trình cho thiết bị.

      :doc:`Khám phá Blockly ↗ <blockly/overview>`

   .. container:: product-card

      .. rst-class:: card-number

      03 / CONNECT

      .. rubric:: LumiSTEM Services

      Hiểu các dịch vụ phía sau ứng dụng. Kết nối dịch vụ local
      để biên dịch và nạp chương trình khi dùng guest.

      :doc:`Tìm hiểu Services ↗ <services/overview>`

Lộ trình đề xuất
----------------

.. container:: flow

   **01. Chuẩn bị** trình duyệt và một thư mục lưu dự án.

   **02. Khám phá** Kitchen nếu bạn muốn tạo tài nguyên riêng.

   **03. Lập trình** bằng các khối lệnh trong Blockly.

   **04. Kết nối** dịch vụ local để đưa chương trình lên bo mạch.

Bạn có thể bắt đầu trực tiếp với Blockly và dùng các khối lệnh có sẵn.
Kitchen là bước tùy chọn khi cần tạo khối lệnh hoặc cấu hình bo mạch riêng.

Làm việc ở chế độ khách
-----------------------

.. note::

   Hãy tải file JSON về máy sau khi chỉnh sửa. File Kitchen và file dự án
   Blockly có cấu trúc khác nhau; mỗi loại cần được mở bằng đúng công cụ.
   Xem :doc:`getting-started/guest` để biết các giới hạn của chế độ khách.

Cần tìm câu trả lời?
--------------------

Sử dụng ô tìm kiếm bên trái hoặc nhấn phím ``/``. Nếu gặp vấn đề khi nhập
file hoặc kết nối thiết bị, xem :doc:`troubleshooting`.
