Lưu và mở dự án
===============

Ở chế độ khách, hãy giữ file dự án trên máy. File JSON cho phép bạn mang
chương trình sang buổi học sau hoặc mở lại trên thiết bị khác.

Lưu dự án
----------

#. Đặt tên dễ nhận biết ở thanh công cụ.
#. Dùng nút lưu hoặc mục lưu trong menu tệp.
#. Giữ file ``ten-du-an.json`` được tải về máy.
#. Sau thay đổi quan trọng, lưu một bản mới và kiểm tra thời điểm tải file.

File dự án chứa trạng thái vùng làm việc và dữ liệu dự án do ứng dụng xuất.
Không đổi nội dung JSON bằng trình soạn thảo nếu bạn chưa biết cấu trúc file.

Mở dự án
---------

#. Lưu công việc đang mở trước khi chuyển sang dự án khác.
#. Chọn mở dự án trong menu tệp.
#. Chọn file JSON đã được xuất từ Blockly.
#. Kiểm tra tên dự án, bo mạch và các khối sau khi tải xong.

Nếu có khối riêng hoặc cấu hình bo mạch riêng, kiểm tra chúng đã được khôi
phục và các chân vẫn đúng với thiết bị đang dùng.

Xuất ảnh
---------

Dùng chức năng chụp hoặc xuất ảnh để lưu hình chương trình cho bài học,
báo cáo hoặc trao đổi. Ảnh dùng để xem; bạn cần file dự án JSON để chỉnh sửa
tiếp trong Blockly.

Phân biệt các loại file
-----------------------

.. list-table::
